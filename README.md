# Reminder Nomor - Pengelola Pendaftaran

Aplikasi pengelolaan pendaftaran dan reminder nomor berbasis Google Apps Script.

## Struktur Project
- `clasp_codelab/`
  - `Code.js`: Server-side logic Apps Script
  - `Index.html`: User Interface web app
  - `appsscript.json`: Manifest Google Apps Script
  - `.clasp.json`: Konfigurasi clasp
